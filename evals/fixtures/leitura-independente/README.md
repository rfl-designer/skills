# Fixtures de `leitura-independente`

Um app Laravel mínimo, só para leitura: Models, Enum, Action, comando, Policy, componente Livewire, rotas e migrations. Ele não roda. Os rascunhos ficam em `rascunhos/`.

Para uma execução, copie `projeto/` e um rascunho para fora do repositório. Dê ao Leitor só essas cópias e a skill. Não dê esta pasta inteira, `evals/cenarios.md` nem os arquivos de resultado: eles descrevem as lacunas plantadas.
